# img 图床

从 WorkBuddy 资料库「img」文件夹导出的 13 张图片，公开托管在此仓库，供 Markdown 文档直接引用。

## 用法

1. Markdown 引用：`![图注](https://cdn.jsdelivr.net/gh/MQ986/img@main/fig1.png)`

2. HTML 引用：`<img src="https://cdn.jsdelivr.net/gh/MQ986/img@main/fig1.png" />`

3. 国内优先用 jsDelivr（`cdn.jsdelivr.net`），直连 `raw.githubusercontent.com` 可能超时

4. 需要永久固定时，把链接里的 `@main` 换成具体 commit 短哈希，例如 `@a1b2c3d`

5. 文件名即地址，入库后不要重命名或移动，否则旧文档中的图片会失效
